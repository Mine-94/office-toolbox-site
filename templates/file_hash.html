개인정보 보호: 파일 읽기와 SHA 계산은 브라우저에서만 처리되며 파일을 서버로 전송하지 않습니다. 파일명·내용·계산된 해시는 분석 이벤트에도 포함하지 않습니다.

브라우저 안에서 계산

선택한 파일을 외부 서버에 업로드하지 않습니다.

표준 SHA 지원

SHA-256·SHA-384·SHA-512 결과를 소문자 16진수로 표시합니다.

공식 값과 비교

공백과 줄바꿈을 제거한 뒤 알고리즘별 길이와 일치 여부를 확인합니다.

파일 무결성 확인 방법

  1. 확인할 파일을 선택합니다.설치 파일·문서·압축파일 등 형식과 관계없이 최대 100MB까지 계산할 수 있습니다.
  2. 공식 안내와 같은 SHA 알고리즘을 고릅니다.배포처가 SHA-256 값을 제공했다면 SHA-256을 선택해야 합니다.
  3. 공식 해시를 붙여넣고 계산합니다.대소문자, 공백, 줄바꿈은 무시하지만 `sha256:` 같은 설명 문구는 제거한 순수한 16진수 값이어야 합니다.
  4. 불일치하면 파일을 사용하지 않습니다.공식 출처에서 다시 내려받고, 계속 다르면 배포처 안내를 확인하세요.

결과를 정확히 해석하는 법

일치

선택한 파일의 바이트와 공식 체크섬의 대상 파일이 같다는 강한 근거입니다. 파일명이 같아도 내용이 한 바이트만 달라지면 결과가 달라집니다.

불일치

파일 버전이나 운영체제용 배포본이 다른지 먼저 확인하세요. 대상이 맞는데도 다르면 손상·변조 가능성이 있으므로 실행하거나 열지 마세요.

알고리즘 선택

SHA-256은 64자, SHA-384는 96자, SHA-512는 128자의 16진수로 표시됩니다. 비교 대상과 알고리즘이 다르면 일치할 수 없습니다.

보안 한계

이 도구는 악성코드 검사가 아닙니다. 해시가 같아도 공식 원본 자체가 안전한지는 별도의 보안 판단이 필요합니다.

지원 범위와 오류 해결

  • Chrome·Edge·Firefox·Safari의 최신 버전처럼 Web Crypto API를 지원하는 보안 연결(HTTPS) 환경에서 동작합니다.
  • 최대 100MB로 제한해 모바일 브라우저의 메모리 부족과 탭 종료 위험을 줄였습니다.
  • 공식 값은 신뢰할 수 있는 공식 배포처의 HTTPS 페이지에서 복사하세요. 블로그·댓글·출처 불명 게시물의 값은 검증 기준으로 쓰지 마세요.
  • 길이 오류가 나오면 알고리즘 선택과 해시 앞뒤의 설명 문구를 확인하세요.

이런 때 사용하세요

설치 파일 확인

프로그램 공식 사이트가 제공한 SHA-256과 내려받은 설치 파일의 값을 비교할 때.

문서 전달 확인

메일이나 메신저로 주고받은 대용량 문서가 전송 중 바뀌지 않았는지 확인할 때.

백업 파일 대조

이름이 같은 원본과 백업본이 실제로 같은 파일인지 각 해시를 계산해 비교할 때.

배포본 기록

납품 파일의 특정 버전을 식별할 수 있도록 SHA 값을 작업 기록에 남길 때.

자주 묻는 질문

선택한 파일이 서버로 전송되나요?

아니요. 파일을 서버로 전송하지 않습니다. 현재 브라우저가 파일을 읽고 Web Crypto API로 해시를 계산합니다.

해시가 같으면 파일이 안전한가요?

해시 일치는 비교한 파일이 같은 바이트로 이루어졌다는 강한 근거입니다. 하지만 이 도구는 악성코드 검사가 아니며, 비교 값은 반드시 신뢰할 수 있는 공식 배포처에서 가져와야 합니다.

MD5나 SHA-1은 왜 없나요?

새로운 무결성 확인에는 더 강한 SHA-256 이상을 사용하도록 SHA-256·SHA-384·SHA-512만 제공합니다. 기존 시스템의 MD5·SHA-1 값과는 비교할 수 없습니다.
