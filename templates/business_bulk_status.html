거래처 Excel 준비 방법

  1. 첫 행에 열 제목을 둡니다.사업자번호 열 이름을 ‘사업자등록번호’ 또는 ‘사업자번호’로 쓰면 가장 안정적으로 찾습니다.
  2. 10자리 번호를 한 열에 정리합니다.하이픈은 있어도 되며 중복 번호는 한 번만 조회합니다. 최대 100개, 파일은 5MB 이하입니다.
  3. 결과 파일의 오른쪽 열을 확인합니다.사업자상태·과세유형·폐업일·확인필요·조회일이 원본 시트 오른쪽에 추가됩니다.

원본 유지 범위와 개인정보

유지되는 항목

기존 시트와 셀 값, 주요 서식을 유지하고 결과 열만 추가합니다. 수식은 수식 상태로 읽어 저장합니다.

지원 범위

원본 유지 방식은 XLSX만 지원합니다. 번호만 불러오는 보조 기능은 CSV와 XLSX를 지원합니다.

조회 한계

미등록·확인불가는 번호 오류나 API 응답 상태도 포함할 수 있습니다. 중요한 거래처는 단건 조회와 서류 대조를 병행하세요.

파일 처리

업로드 파일을 디스크나 데이터베이스에 별도 보관하지 않고 요청 처리 메모리에서 읽습니다. 사업자번호는 조회를 위해 국세청 API로 전달됩니다.

처리되지 않을 때

  • 열을 찾지 못하면 첫 행에 정확한 열 제목을 추가하고, 사업자번호가 숫자 10자리인지 확인하세요.
  • 사업자번호로 보이는 열이 여러 개라면 실제 조회할 한 열만 ‘사업자등록번호’로 이름을 정리하세요.
  • 100개를 넘으면 파일을 나누고, 공공 API 응답이 지연되면 잠시 뒤 다시 시도하세요.

자주 묻는 질문

기존 Excel의 거래처명이나 금액 열이 사라지나요?

아니요. 원본 워크북의 기존 열과 시트를 유지하고, 사용 중인 시트 오른쪽에 업무 도구함 조회 결과 열을 추가합니다.

어떤 Excel 형식이 가장 잘 인식되나요?

첫 행에 열 제목이 있고 사업자번호 열 제목이 ‘사업자등록번호’ 또는 ‘사업자번호’인 XLSX 파일이 가장 안정적으로 인식됩니다.

몇 개까지 처리할 수 있나요?

현재 버전은 한 파일에서 중복을 제외한 최대 100개 사업자등록번호까지 처리합니다.
