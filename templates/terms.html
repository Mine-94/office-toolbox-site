이용약관

시행일: 2026년 9월 5일

1. 서비스와 운영 주체

사무실 도구함(이하 "서비스")은 Lichtbringer가 운영하며 PDF·이미지·텍스트 처리, 업무 계산, 사업자 상태조회 등 업무 중 자주 사용하는 온라인 도구를 무료로 제공합니다. 각 도구의 지원 형식과 처리 한도는 해당 페이지의 안내를 따릅니다.

2. 이용 조건과 이용자의 책임

이용자는 저작권 등 제3자의 권리를 침해하지 않는 파일과 데이터만 입력·업로드해야 하며, 불법적이거나 부적절한 콘텐츠를 처리 목적으로 사용해서는 안 됩니다.

3. 파일 처리와 개인정보

업로드가 필요한 도구는 작업을 위해 파일을 일시적으로 처리합니다. 삭제 시점, 공공데이터 API 전달, 이용 통계와 광고 관련 처리는 개인정보처리방침과 각 도구 페이지의 안내를 따릅니다. 기밀 문서는 처리 방식과 조직의 보안 규정을 확인한 뒤 사용해야 합니다.

4. 결과의 정확성과 한계

서비스는 안정적인 제공과 정확한 결과를 위해 노력하지만, 파일 구조·원본 품질·브라우저 환경·외부 API 장애·법령이나 요율 변경에 따라 결과가 달라질 수 있습니다. 사업자 상태, 급여 예상액과 세액 등 중요한 업무 판단에는 조회 기관의 최신 공식 자료와 원본 문서를 함께 확인해야 합니다. 서비스 결과는 세무·노무·법률 자문을 대신하지 않습니다.

5. 금지되는 사용

서비스 장애를 일으키는 자동화 요청, 처리 한도 우회, 악성 파일 유포, 타인의 권리를 침해하는 파일 처리, 광고의 인위적 클릭이나 클릭 유도 행위를 금지합니다. 안정성과 보안을 위해 비정상적인 요청은 제한할 수 있습니다.

6. 광고와 이용자 보호

서비스 운영비를 충당하기 위해 페이지에 광고가 게재될 수 있습니다. 광고는 도구의 입력·결과 영역과 구분하며, 특정 광고의 클릭을 요구하거나 도구 사용을 광고 클릭 조건으로 삼지 않습니다.

7. 서비스 변경과 중단

오류 수정, 보안, 외부 API 변경이나 운영상의 필요에 따라 기능을 변경하거나 일시 중단할 수 있습니다. 정확성을 충분히 설명하기 어려운 기능은 URL을 즉시 삭제하기보다 검색 노출을 중단한 상태에서 먼저 개선합니다.

8. 문의와 약관의 변경

기능 오류, 설명 정정과 운영 정책에 관한 문의는 문의하기에서 접수합니다. 본 약관을 변경하는 경우 이 페이지의 시행일과 내용을 함께 갱신합니다.
